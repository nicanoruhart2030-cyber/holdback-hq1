# Fernando Uhart · DJ website

A static site (HTML, CSS, JS, no build step). Open `index.html` in a browser, or deploy the folder to any static host (Netlify, Vercel, GitHub Pages).

## Before going live

1. **Photo:** save the photo of Fernando behind the decks as `images/fernando-decks.jpg` (portrait, about 4:5, at least 1000px wide). Until then the hero shows an illustrated placeholder.
2. **WhatsApp and Instagram:** at the top of `script.js`, set `WHATSAPP_NUMBER` (international format, digits only, e.g. `5492231234567`) and `INSTAGRAM_URL`.
3. **Booking form:** with a WhatsApp number set, submitting the form opens WhatsApp with the request pre-filled. To receive requests by email instead, connect the form to a service such as Formspree.
